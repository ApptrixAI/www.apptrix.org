## Not a wrapper. A real native app.

Most visual app builders hand you a web view in a native costume. Apptrix
compiles to a genuine native binary built on [Fyne](https://fyne.io), the Go GUI
toolkit. There is no bundled browser, no JavaScript runtime, and no gap between
what you designed and what your users run.

That has consequences you can feel. Apps start instantly. They work offline
because nothing was ever waiting on a server. They ship as a single file. And
because the output is ordinary Go, you can drop into code whenever the visual
layer stops being the fastest way to express what you mean.

## What lives here

**Apptrix.org** is the open source home of Apptrix projects. Two things live here:

The **Community Build** — the Apptrix editor, free for open source developers.
It is the same designer, the same compiler, the same native output as the
commercial product. What it leaves out is the AI assistance and the hosted build
server; everything else is here.

Our **open source components** — widgets and libraries we develop in the open
for the wider Fyne ecosystem. They are useful in any Go application, whether or
not you ever open Apptrix.

The commercial platform, with offline AI inference and cloud builds for teams,
lives at [apptrix.ai](https://apptrix.ai).
