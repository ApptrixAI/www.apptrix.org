## Building your first app

Apptrix produces a native binary, so it builds through the Go toolchain on your
own machine. Before your first build you will need:

- **Go** 1.19 or newer.
- **A C compiler** — Xcode command line tools on macOS, GCC or Clang on Linux, or
  the MinGW-w64 toolchain on Windows.
- **Platform SDKs, only for mobile** — Xcode for iOS, and the Android SDK and NDK
  for Android. Desktop targets need neither.

The [Fyne getting started guide](https://docs.fyne.io/started/) covers the
toolchain setup in detail; once it can build a Fyne app, it can build an Apptrix
one.
