A collection of advanced widgets that go beyond the Fyne toolkit's standard set.
Use them in any Fyne app — you do not need Apptrix to build with them.

## Chat

A ready-made chat interface with a small API, so a conversational surface is a
few lines rather than a subproject.

## WebView

A rich web widget that renders through each system's own web engine rather than
bundling a browser. Supported on macOS, Windows, Linux (X11), Android and iOS.
Linux Wayland support is in progress.
